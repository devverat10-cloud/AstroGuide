# AstroGuide — Mobile Onboarding & Retention Architecture
> A 3-step high-conversion mobile user journey designed in Figma using the **Warm Vedic Trust** aesthetic.

![AstroGuide Figma Prototype Flow 1](img/astroguide-user-flow.png)

## 🌟 Overview
AstroGuide is a mobile app connecting spiritual seekers with certified Vedic astrologers. This case study focuses on **Flow 1**: a frictionless 3-stage user journey engineered to eliminate drop-off, build instant spiritual trust, and incentivize first-session consultations.

## 🎨 Visual Direction ("Warm Vedic Trust")
Instead of using the clichéd dark-purple and mystical star theme, this project uses a grounded **Warm Vedic Trust** palette:
- **Calming Ivory Canvas:** `#FAF8F5`
- **Warm Amber / Saffron:** `#E65100`
- **Deep Charcoal Typography:** `#1A1D20` in *Plus Jakarta Sans*

## 💡 Key Design Decisions
1. **Contextualizing the 100 Coins:** Rather than simply displaying "You received 100 coins", purchasing power is broken down into 3 clear cards (Instant Chat, Audio Consultation, Kundali Session) so first-time users immediately grasp value.
2. **Passwordless Phone Auth:** Pre-filled `+91` flag with a 4-digit auto-read OTP ensures rapid onboarding for users across metro and tier-2/3 towns.
3. **Accessible Touch Targets:** 52px primary action buttons and clean micro-interactions tailored for effortless touch usability.
